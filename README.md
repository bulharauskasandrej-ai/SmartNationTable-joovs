# SmartNation grades dashboard

Личный сайт для просмотра аттестаций и оценок из SmartNation. Код хранится в GitHub, а сайт вместе с Python API запускается на Render. GitHub Pages для этой версии не подходит: он не запускает сервер, который нужен для безопасного входа.

## Публикация

1. Создай **приватный** GitHub-репозиторий.
2. Загрузи в него файлы приложения: `.gitignore`, `README.md`, `render.yaml`, `requirements.txt`, `student_grades.py`, `student_grades_site.py` и папку `site`.
3. **Не загружай** файлы `*_raw.json`: это сохранённые ответы журналов, в которых могут быть личные данные учеников. `.gitignore` исключает их при обычной работе с Git.
4. На Render выбери **New → Blueprint**, подключи свой GitHub-репозиторий и подтверди создание сервиса из `render.yaml`.
5. Открой выданный Render URL. Вход и оценки будут доступны через этот адрес по HTTPS.

Render запускает Python-сервер, обслуживающий и сайт, и API на одном домене. ИИН и пароль используются только для запроса входа в SmartNation; пароль не сохраняется приложением. Загруженные оценки держатся только в памяти сервера до выхода, окончания сессии или перезапуска сервиса.

На бесплатном тарифе Render сайт может засыпать после периода бездействия, а перезапуск завершает активные сеансы. Реальный вход зависит от того, принимает ли SmartNation запросы с внешнего сервера; проверь его после публикации, вводя пароль только на своём сайте.

## Локальный запуск

Установи зависимости командой `python -m pip install -r requirements.txt`, затем запусти `start_site.bat`.
